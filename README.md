# 💾 Backup System

Bash-скрипт для автоматического резервного копирования с логированием и версионированием через Git.

## ✨ Возможности

- 📦 Создание сжатых архивов (`tar.gz`) выбранной папки
- 📝 Логирование каждой операции в отдельный файл
- 🕐 Автоматический запуск по расписанию через `cron`
- 🧹 Автоочистка старых бэкапов (хранит только 5 последних)
- 📊 Информативный вывод (размер, время, статус)
- 🔒 Безопасность: логи не попадают в Git

🚀 Быстрый старт

# Клонировать репозиторий
git clone https://github.com/Ostenvrn/backup-system.git
cd backup-system

# Сделать скрипт исполняемым
chmod +x backup.sh

# Запустить бэкап папки
./backup.sh ~/Документы

Как это работает
bash

# 1. Скрипт принимает путь к папке
./backup.sh /путь/к/папке

# 2. Создаёт архив с датой в имени
#    → ~/backups/backup_2026-09-11_15-30.tar.gz

# 3. Пишет запись в лог
#    → logs/backup.log

# 4. Удаляет старые бэкапы (оставляет 5 последних)

🕐 Автоматический запуск (cron)

Открой редактор расписания:

crontab -e

Добавь строку (замени USER на своё имя пользователя):
bash

0 2 * * * /home/USER/backup-system/backup.sh /home/USER/Документы >> /home/USER/backup-system/logs/cron.log 2>&1

Теперь бэкап будет создаваться каждый день в 2:00 ночи.

📝 Логирование

Все операции записываются в logs/backup.log:

[2026-09-11 15:30:00] Начинаю бэкап папки: /home/User/Документы
[2026-09-11 15:30:02] ✅ УСПЕХ! Создан архив: backup_2026-09-11_15-30.tar.gz (Размер: 1240 KB)
[2026-09-11 15:30:02] Чистка старых бэкапов (оставляю 5)
[2026-09-11 15:30:02] -------------------------

🧰 Технологии

    Bash — написание скрипта

    tar — архивация

    cron — автоматизация по расписанию

    Git — версионирование кода

🔒 Безопасность

    Логи не попадают в Git (исключены через .gitignore)

    Скрипт проверяет существование папки перед архивацией

    Бэкапы не публикуются в репозиторий

📋 Команды

./backup.sh /путь/к/папке	Создать бэкап указанной папки

cat logs/backup.log	Посмотреть лог операций

ls ~/backups/	Список всех созданных бэкапов

crontab -l	Проверить расписание автозапуска
